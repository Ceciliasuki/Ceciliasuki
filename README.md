# Ceciliasuki

我是中央财经大学应用统计学与国际经济与贸易双学位在读学生。自 2025 年参与行业系统性风险建模以来，我持续在金融、人工智能和统计学领域做研究，也把论文阅读、数据分析和研究记录中常用的功能做进了 ACAORA。

## 研究方向

**金融｜行业风险与市场数据**  
在行业系统性风险预警项目中，我参与构建财务、市场和舆情特征，用 XGBoost 做风险分级，并以 Logistic 回归和 SVM 为对照。我也关注如何从 A 股舆情数据中构造可用于实证分析的指标。

**人工智能｜模型评测与人工复核**  
我从原文证据、财务口径和计算过程入手，分析大模型在财报问答中怎样出错。我也在研究多个模型可能共同出错时，有限的人工复核名额该如何分配，并用有限博弈和线性规划求解复核策略。

**统计学｜抽样设计与文本分析**  
我参与比较人类撰写与 AI 生成的学术摘要，从分层抽样和样本可比性入手，结合统计检验和共词网络，考察两类摘要在语言特征与术语关联上的差异。

## 项目

### ACAORA 学曦 · 开源，已上线

我独立开发的学习与研究工作台。读论文时，可以把摘录和笔记留在原文旁；做实证分析时，可以记录数据来源、模型设定和运行结果，并把结果关联到项目里的正文。使用 Next.js、TypeScript 和 Supabase 构建，通过 Playwright 和 GitHub Actions 检查关键流程。

[在线体验](https://acaora.cn) · [源码与使用说明](https://github.com/Ceciliasuki/acaora) · [研究流程实现](https://github.com/Ceciliasuki/acaora/blob/main/docs/reviews/2026-10-25-connected-research-tools.md)

### 研报明镜 · 财报核验与研报纠错

在团队项目中，我参与搭建财报核验流程。系统从研报中提取待核查的陈述，定位对应财报页和表格，经人工确认后核对金额和单位、复算同比，并给出可追溯到原文的纠错建议。
