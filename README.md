## 代表项目

### ACAORA 学曦 · 实证研究工作台

平台把文献证据、数据版本、模型设定和分析结果关联到同一研究项目。研究者可以从正文引用回到原始材料和分析记录，来源发生变化时，系统会标记需要复核的结果。工程上实现了账号与项目权限隔离，并用自动化测试验证关键流程。[研究工作台实现](https://github.com/Ceciliasuki/acaora/blob/main/docs/reviews/2026-10-25-connected-research-tools.md)

### 研报明镜 · 金融 AI 核验工具

我参与设计并实现团队的研报核验流程。大模型提取待核查的财务陈述，程序按确认后的指标口径复算，核验人可以对照财报原页判断差异。每条纠错建议都关联相应的证据。

## 研究方向

自 2025 年以来，我的研究涵盖行业风险建模、金融大模型评估与统计文本分析。近期研究关注多个模型可能共同失效、评分存在不确定性时，如何在有限的人工复核容量下制定稳健的复核策略。
