我是中央财经大学应用统计学与国际经济与贸易双学位在读学生。我关注两个问题：怎样用大模型辅助金融研究，以及怎样把结果追溯到原文和计算过程。我用 Python 做数据处理、统计建模与模型评测，也用 TypeScript 把研究流程做成能实际使用的工具。

## 项目

### ACAORA 学曦 · 开源，已上线

我独立开发的学习与研究工作台。读论文时，可以把摘录和笔记留在原文旁；做实证分析时，可以记录数据来源、模型设定和运行结果，并把结果关联到项目里的正文。使用 Next.js、TypeScript 和 Supabase 构建，通过 Playwright 和 GitHub Actions 检查关键流程。

[在线体验](https://acaora.cn) · [源码与使用说明](https://github.com/Ceciliasuki/acaora) · [研究流程实现](https://github.com/Ceciliasuki/acaora/blob/main/docs/reviews/2026-10-25-connected-research-tools.md)

### 研报明镜 · 财报核验与研报纠错

在团队项目中，我参与搭建财报核验流程。系统从研报中提取待核查的陈述，定位对应财报页和表格，经人工确认后按统一口径复算金额、单位和同比，给出能回到原文的纠错建议。

## 研究方向

- **金融大模型评测**：关注财报问答的证据、计算与失败类型，以及复核资源有限时怎样安排人工核查。
- **统计建模与数据分析**：关注金融风险和文本数据，重视样本构造、数据质量与结果复查。
