## 产品与系统

### ACAORA 学曦 · 实证研究工作台

独立完成产品定义、系统架构、全栈开发与生产部署。平台把文献证据、数据版本、模型设定和分析结果关联到同一研究项目。研究者可以从正文引用回到原始材料和分析记录，来源变化时，系统会标记需要复核的结果。[研究工作台实现](https://github.com/Ceciliasuki/acaora/blob/main/docs/reviews/2026-10-25-connected-research-tools.md)

### 研报明镜 · 金融 AI 核验工具

参与设计和实现研报核验流程，把大模型提取、财报原页定位、指标口径确认、程序复算和人工签核串在一起。每条纠错建议都可以回到相应的财报证据。

### 会话罗盘 · Windows 桌面助手

开发 Windows 桌面工具，整合屏幕文字识别、图片理解与本地语音转写。用户可以在生成草稿前核对原话和上下文。构建流程会校验运行包，更新失败时保留可用版本。

### 诗境 · 古典文学阅读产品

为古诗文设计数字阅读体验，将正文标号、页下注释和长文分页结合起来。读者可在原文与注释间跳转，保存收藏和札记，并导出阅读记录。

## 数据与研究

- **A 股舆情与风险研究**。构建从多源标题采集、去重、批量情绪标注到股票周度汇总的处理流程，按来源核对数据覆盖、缺失和评分结果，为后续风险分析准备研究数据。
- **A 股量化研究平台**。建立行情数据验收与版本快照流程，将数据可用时点、交易约束和验证规则纳入策略研究设计。
- **今经乐道 · 年报问答评测**。围绕上市公司年报设计问答任务，逐题复核来源、财务口径与计算，对照模型配置的交付质量、调用费用和响应时间。
- **金融大模型复核决策**。用有限博弈与线性规划研究模型共同失效、评分不确定和复核容量有限时，如何安排人工复核。
- **学术摘要与共词网络**。比较人类撰写和 AI 生成的学术摘要，围绕样本构造、统计检验与共词网络分析研究两类文本的语言特征。
